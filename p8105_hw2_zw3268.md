nyc_subway_entrance_exit_data = read_csv(
  file = "./data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",

    line,

    station_latitude,
    station_longitude,
    route1:route11,
    entry,
    vending,
    entrance_type,
    ada) |>
  mutate(
    entry = case_match(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE))

### Dataset description

Each row describes a NYC subway entrance or exit, so stations may appear
more than once. Variables include the line, station name and location,
routes, entry permission, vending, entrance type, and ADA compliance. I
cleaned the column names, kept the requested variables, converted entry
from YES/NO to TRUE/FALSE, and read Route8–Route11 as character columns
for consistent route types. The cleaned data have 1868 rows and 19
columns. They are not tidy yet because routes are spread across 11
columns instead of one variable.

### Routes and A train stations

``` r
nyc_subway_route_data =
  nyc_subway_entrance_exit_data |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name") |>
  drop_na(route_name)

number_of_a_train_stations =
  nyc_subway_route_data |>
  filter(route_name == "A") |>
  distinct(line, station_name) |>
  pull(station_name) |>
  length()

number_of_ada_compliant_a_train_stations =
  nyc_subway_route_data |>
  filter(route_name == "A", ada == TRUE) |>
  distinct(line, station_name) |>
  pull(station_name) |>
  length()
```

I reshaped the routes into `route_number` and `route_name` and removed
empty slots. Using line and station name to identify distinct stations,
the A train serves 60 stations, of which 17 are ADA compliant.
